# LabelTrace

LabelTrace answers questions about two migraine medicines, **Emgality** and **Reyvow**,
using only their official FDA drug labels.

**LabelTrace is an AI, not a doctor.**

## Status

LabelTrace is **in development and not live yet**. There is no public website. It can only
be run on your own computer for testing.

## What it can't do

- **No personal advice.** It won't tell you what dose to take or whether a medicine is
  right for you. Ask your doctor or pharmacist.
- **No comparisons.** It won't say whether one medicine is better than another.
- **English only.** Questions in other languages aren't answered.
- **Not a doctor.** It only repeats what the label says.
